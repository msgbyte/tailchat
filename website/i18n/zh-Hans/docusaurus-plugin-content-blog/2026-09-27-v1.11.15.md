- 新增基于 IP 的注册频率限制（包含游客注册），用于抑制批量注册
  - 默认每个 IP 每小时最多 3 次、每天最多 10 次，可通过环境变量 `REGISTER_IP_LIMIT_PER_HOUR` 与 `REGISTER_IP_LIMIT_PER_DAY` 调整
  - 配额通过 Redis 在所有实例间共享；如果部署在反向代理之后，请确保代理正确转发真实客户端 IP，详见[环境变量文档](/docs/deployment/environment)
- Socket.IO 连接现在会按照与 HTTP 请求相同的规则记录客户端 IP，登录 IP 记录等依赖 IP 的功能在不同连接方式下保持一致
- 新版管理后台改进：
  - 侧边栏支持折叠为仅图标模式
  - 用户搜索支持 `昵称#唯一标识` 格式
  - 表格列宽支持拖拽调整
  - 修复后端图片地址无法正确解析的问题，修复用户操作菜单项未对齐的问题
- 安全：`friend.buildFriendRelation` 调整为仅限内部服务调用，不再允许通过 HTTP 或 Socket.IO 直接调用，好友关系必须通过申请 / 同意流程建立
- 移除 `com.msgbyte.ai-assistant` 插件
- Docker 镜像改为多阶段构建，运行时镜像体积明显减小
