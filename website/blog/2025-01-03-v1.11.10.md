- Security: markdown output is now sanitized with `rehype-sanitize`, and raw HTML tags are no longer supported in markdown.
- Files uploaded from the chat box are now tagged with their usage, and the admin file page can filter by usage, which makes cleanup easier.
- Nickname rendering keeps a placeholder to avoid flickering on hover.
