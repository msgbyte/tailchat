- Added the `DISABLE_TRACING` environment variable to turn off tracing, which saves a large amount of log output.
- Markdown: embedded iframes no longer autoplay, and fixed an issue where `meta` tags could be rendered.
- Admin: improved the file table display, and the "chat images" filter now excludes group avatars and backgrounds.
- Adjusted the spacing of system messages.
