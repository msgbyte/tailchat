- Reworked read-state (ack) loading to only fetch the conversations that are needed instead of all of them, which speeds up startup for accounts with many conversations.
- Security: custom styles are no longer allowed in markdown rendering (#252).
- Added the `DISABLE_INFO_LOG` environment variable to keep only error logs.
- Fixed a list crash when user information is empty.
- Refreshed the offline icon set.
- Docs: added a BT Panel (宝塔) deployment guide.
