- Added the `chat.message.getMessage` OpenAPI endpoint so bots can fetch a single message by its ID (#227).
- Added the `TIANJI_SCRIPT_URL` and `TIANJI_WEBSITE_ID` environment variables to integrate [Tianji](https://tianji.msgbyte.com/) website analytics, see the [environment variables documentation](/docs/deployment/environment).
- Fixed the quick switcher (`ctrl+k`) being covered by other layers, and removed group panel types that cannot be opened directly from its results.
- Updated the external storage documentation.
